# Data Engineering

This repository contains notes, examples, assignments, and projects for learning data engineering with **Apache Spark and PySpark**.

## Topics Covered

- Big data and Hadoop
- HDFS and MapReduce
- Apache Spark and PySpark
- RDDs, DataFrames, and Spark SQL
- Joins, aggregations, windows, and optimization
- Partitioning, caching, and file formats
- Data lakes, data warehouses, and lakehouses
- Testing, logging, and productionizing PySpark applications
